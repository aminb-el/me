Project Overview

A short introduction to the Truth / Perceived Truth / Importance framework and the empirical work built around it.

Already familiar with this project?
If you have already read an overview elsewhere in my application, feel free to skip this overview and continue →

I built a mathematical framework for evaluating statements without collapsing different questions into a single score. Instead, the framework produces three separate outputs:

Tabs — evidence-weighted truth.
Tperc — perceived truth for a particular receiver.
I — receiver-dependent importance.

The theoretical model is organized around fifteen axioms and six input clusters covering the source, the statement itself, delivery, situational context, the receiver, and corroborating evidence. These inputs are combined through a sequential Bayesian update architecture.

During development, I encountered cases where the original model behaved incorrectly. For example, an internally coherent but effectively unfalsifiable statement could receive too much weight, and a high-stakes situation could make an unrelated statement appear more important than it should. I revised the framework by introducing a stronger falsifiability condition and a relevance gate that controls how much surrounding context actually belongs to the statement being evaluated.

I then tested the framework empirically on three public datasets, with different datasets corresponding to the three outputs: HumAID for importance, CREDBANK/CredEvent for perceived credibility, and LIAR/PolitiFact for evidence-weighted truth.

The evaluation separates external, target-free assignment of atomic variables from the mathematical computation of the final outputs. This portfolio shows both the framework itself and the process through which it was implemented, corrected, tested, and revised.
