What Changes When the Inputs Change?

I tried several controlled changes after building the worked example. In each experiment below, everything remains fixed except the variable explicitly named.

Original worked example
Tabs
0.3246
Tperc
0.8918
I
0.9833
Experiment 1 — Remove falsifiability
H: 0.98 → 0
Original H = 0
Statement composite 0.8878 0.0000
Tabs 0.3246 0.0107
Tperc 0.8918 0.1567
I 0.9833 0.9780

Setting falsifiability to zero makes the statement term itself collapse to zero. This is a direct consequence of the factor 1 − e−kH introduced during the falsifiability repair.

The truth value therefore falls sharply. Perceived truth also falls because it begins from the truth value as its anchor.

Importance behaves very differently. It remains high because the receiver still has an exam the next morning and the message still has immediate consequences for that receiver. Truth enters the importance branch only as a dampened update.

Experiment 2 — Remove contextual relevance
Rel(s,c): 0.98 → 0
Original Rel = 0
Situational composite 0.4554 0.3566
Tabs 0.3246 0.3246
Tperc 0.8918 0.8573
I 0.9833 0.9740

The part I find most useful here is what does not change: the truth value remains exactly the same.

Relevance belongs to the situational path. It affects perceived truth and importance, but it is not an input to evidence-weighted truth. Changing it therefore leaves Tabs untouched.

Also, setting relevance to zero does not erase the entire situation. The relevance gate pulls the gated stakes variables toward their neutral points. Other situational and receiver variables remain in the computation.

Experiment 3 — Change both at once
H = 0 and Rel(s,c) = 0
Original Both = 0
Tabs 0.3246 0.0107
Tperc 0.8918 0.1194
I 0.9833 0.9659

With falsifiability removed and the surrounding stakes gated toward neutral, the truth and perceived-truth values both become very low.

Importance still remains high. The reason is not the truth branch or the relevance-gated stakes. The receiver still has a very high personal-consequence input, the message still arrives at an actionable time, and the remaining delivery and receiver terms continue to contribute.

These experiments show why I kept the three outputs separate.

Changing one property of a statement does not have to move truth, perceived truth, and importance in the same direction or by the same amount.

A result I would still investigate

The persistence of the importance value is also a useful challenge to the current model. Even with H = 0 and Rel(s,c) = 0, importance remains at 0.9659 in this scenario.

There is a structural reason for that result: the receiver consequence, receiver novelty, timing, and other delivery inputs remain strong, while truth is deliberately dampened inside the importance branch.

But the remaining question is empirical: is that persistence appropriately strong? The current framework can explain why the value remains high; further calibration is needed to determine whether the magnitude is right.
